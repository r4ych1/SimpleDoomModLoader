# Feature 009 - Collapsible File Library Pane

## Status
Feature 009 is superseded by Feature 014.

## Historical Note
- Feature 009 introduced the old pane-collapse model for the right-side file library.
- Feature 014 replaces that model with a single shared workspace that swaps between `Profiles` and `File Library` views.
- Implementations and future changes must follow Feature 014 instead of reintroducing hidden-pane, profile-only-mode, or remembered-width behavior from Feature 009.
